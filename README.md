Lua
===

This repository contains all official Lua addons and scripts for Windower v4.

Lua documentation and a guide on writing and submitting addons can be found at the Windower development wiki: https://dev.windower.net/

## ConsoleBG+ development

The `consolebg-plus` branch contains the ConsoleBG+ experiment. Start with [TESTING.md](TESTING.md) for current status and [WORKFLOW.md](WORKFLOW.md) for shared development guidance. Configuration and cumulative addon changes are in [the ConsoleBG+ README](addons/ConsoleBGPlus/README.md).
