The addon unpacks its bundled PNG frame pieces here on first load.

Source images: Tylas11/XivParty `assets/ffxi/BgTop.png`, `BgMid.png`, and `BgBottom.png`.
See `../LICENSE.txt` for the notices.

v0.1.1 uses the complete 64-pixel native right fade in every frame row and
divider. The glow pieces retain the same stripes and alpha mask; the small
grey tab is generated by `tools/consolebgplus/build_skin.py`. The current
files use the `cbgplus_v2_` prefix. Older v1 files are unused and harmless.
